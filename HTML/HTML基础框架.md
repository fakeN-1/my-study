HTML的基础框架

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    
</body>
</html>
```

html是一种标记语言,采用标签的形式进行编写,所有标签都在尖括号内:
```
<text>
<div></div>
<div> <div> </div> </div>
```
