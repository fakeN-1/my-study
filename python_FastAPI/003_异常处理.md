# 异常处理
- 对于客户端引发的错误,需要使用fastapi.HTTPException来中断正常处理流程.并且返回标准错误响应.
- 异常处理步骤:
1. 导入异常处理的HTTPException模块
2. 设置异常的条件(比如:if....)
3. 使用raise抛出(reise HTTPException)
```
from fastapi import FastAPI,HTTPException
app = FastAPI()
# 需求,按照id查询新闻:1-6查询.
@app.get("/news")
async def get_news(id:int):
    id_list=[1,2,3,4,5,6]
    if id not in id_list:
        raise HTTPException(status_code=404,detail="您查找的新闻不存在")
    return {"id":id}
```
- 这里面的status_code是状态码.
- detail是注释.
