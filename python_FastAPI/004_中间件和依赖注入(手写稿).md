# 中间件
- 是指再每次请求进入FastAPI应用时都会被执行的函数.
- 中间件的执行顺序是按照代码的顺序,自下而上执行.
- 中间件的写法:
```
from fastapi import FastAPI
app = FastAPI()
# 中间件
@app.middleware("http")
async def middleware1(request,call_next):
    print("中间件1开始执行,strat")
    response = await call_next(request)
    print("中间件1结束执行,end")
    return response
@app.middleware("http")
async def middleware2(request,call_next):
    print("中间件2开始执行,strat")
    response = await call_next(request)
    print("中间件2结束执行,end")
    return response
@app.get("/")
async def home():
    return {"message": "Hello World"}
```
1. 首先使用装饰器:@app.middleware("http")
> 使用这个装饰器装饰的函数就会变成中间件
2. 之后定义一个函数,这个函数必须包括两个参数: ***请求***和***传递请求给路径的函数***
> async def middleware(request,call_next)
3. 最后向下传递请求call_next(request),赋值为response,输出
> response = await call_next(request)

# 依赖注入
- 依赖注入主要是注入系统来共享通用的逻辑,减少代码重复.


```
from fastapi import FastAPI, Depends, Query

app = FastAPI()

@app.get("/")
async def home():
    return {"message": "Hello World"}
# 依赖注入
# 分页参数系统公用,新闻列表和用户列表
async def conmmon_paremeters(
        skip: int = Query(0,ge=0),
        limit: int = Query(10,le=60),
):
    return {"skip": skip, "limit": limit}
@app.get("/new/new_list")
async def new_list(commons=Depends(conmmon_paremeters)):
    return {"message": commons}
@app.get("user/user_list")
async def user_list(name: str):
    return {"message": "Hello user"}
```
- 在以上的代码中new_list函数注入了依赖,而user_list没有注入依赖.


# 中间件和依赖注入的区别
- 中间件必定执行,依赖注入可以选择执行,单独执行.
> 简单来说中间件是所有接口通用的,依赖注入可以指定接口(一次编写多次使用).
