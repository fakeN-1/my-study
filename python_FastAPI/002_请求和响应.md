# FastAPI：请求和响应

## 1. 什么是响应？

客户端向 FastAPI
发送请求，服务器处理后，需要把结果返回给客户端，这个过程就是**响应（Response）**。

``` text
客户端                         FastAPI 服务器
   |                                |
   | -------- 发送请求 ------------> |
   |                                | 处理请求
   | <-------- 返回响应 ------------ |
   |                                |
```

FastAPI 默认会把常见的 Python 数据转换成 JSON 格式，再通过 HTTP
响应返回给客户端。

例如：

``` python
from fastapi import FastAPI

app = FastAPI()

@app.get("/user")
async def get_user():
    return {
        "id": 1,
        "name": "Yui"
    }
```

访问 `/user`，响应内容为：

``` json
{
  "id": 1,
  "name": "Yui"
}
```

> 记忆：默认情况下，返回字典、列表等数据时，FastAPI 会将其转换为 JSON
> 响应。若要返回 HTML、文件等其他形式，需要使用相应的响应类。

## 2. 设置响应类型：`response_class`

有时我们不希望返回
JSON，而是希望浏览器显示网页、返回文件或纯文本。这时可以使用 FastAPI
提供的响应类。

### 2.1 HTMLResponse：返回 HTML 页面

**作用：** 将返回内容作为 HTML 响应，让浏览器按照 HTML 进行解析和渲染。

``` python
from fastapi import FastAPI
from fastapi.responses import HTMLResponse

app = FastAPI()

@app.get("/html", response_class=HTMLResponse)
async def get_html():
    return "<h1>Hello World</h1>"
```

访问：

``` text
http://127.0.0.1:8000/html
```

浏览器会把字符串解析为 HTML，显示一个一级标题：**Hello World**。

这里重点看：

``` python
response_class=HTMLResponse
```

它表示这个接口使用 HTML 响应类型，而不是默认的 JSON 响应类型。

### 2.2 FileResponse：返回文件

**作用：** 将服务器上的文件作为 HTTP 响应返回给客户端。

可以用于返回图片、PDF、Excel 等文件。

``` python
from fastapi.responses import FileResponse

@app.get("/file")
async def get_file():
    path = "files/1.jpeg"
    return FileResponse(path)
```

这里的 `path` 是**服务器本地文件系统中的文件路径**，不是浏览器访问的
URL。

例如，项目目录结构如下：

``` text
FastAPI_first/
│
├── main.py
│
└── files/
    └── 1.jpeg
```

可以使用更稳妥的路径写法：

``` python
from pathlib import Path
from fastapi.responses import FileResponse

BASE_DIR = Path(__file__).resolve().parent

@app.get("/file")
async def get_file():
    path = BASE_DIR / "files" / "1.jpeg"
    return FileResponse(path)
```

> 注意：文件必须真实存在。`FileResponse`
> 返回的是服务器上的文件；如果路径错误或文件不存在，就无法正常返回。

## 3. 自定义响应数据类型：`response_model`

前面学习的 `HTMLResponse` 和 `FileResponse` 主要解决的是响应形式问题。

如果希望规定接口返回的数据必须包含哪些字段、每个字段是什么类型，就可以使用
`response_model`。

这里需要用到 **Pydantic 的 BaseModel**。

### 3.1 定义数据模型

``` python
from pydantic import BaseModel

class News(BaseModel):
    id: int
    name: str
    content: str
```

这个模型规定了 News 数据应当具有三个字段：

  字段      数据类型   含义
  --------- ---------- ----------
  id        int        新闻 ID
  name      str        新闻名称
  content   str        新闻内容

### 3.2 在路由中使用 response_model

``` python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class News(BaseModel):
    id: int
    name: str
    content: str

@app.get("/news/{id}", response_model=News)
async def get_news(id: int):
    return {
        "id": id,
        "name": f"这是来自于{id}的书",
        "content": "这是一本好书"
    }
```

例如访问：

``` text
http://127.0.0.1:8000/news/1
```

返回：

``` json
{
  "id": 1,
  "name": "这是来自于1的书",
  "content": "这是一本好书"
}
```

### 3.3 response_model 的作用

`response_model=News` 主要有以下作用：

1.  **数据验证：** 检查返回的数据是否符合 News 模型。
2.  **数据转换：** 按照模型规定的类型处理响应数据。
3.  **数据过滤：** 默认只输出模型中声明的字段。
4.  **接口文档：** 自动在 `/docs` 中生成对应的响应结构说明。

例如：

``` python
@app.get("/news/{id}", response_model=News)
async def get_news(id: int):
    return {
        "id": id,
        "name": "新闻标题",
        "content": "新闻内容",
        "password": "123456"
    }
```

虽然返回字典中包含 `password`，但它不在 News
模型中，因此默认不会出现在最终响应中。

> 注意：如果返回的数据不符合响应模型要求，例如缺少必要字段或类型无法处理，FastAPI
> 会产生响应验证错误。这通常属于服务器端错误，而不是客户端提交参数错误。

## 4. response_class 和 response_model 的区别

这是本章最重要、最容易混淆的知识点。

  对比         response_class               response_model
  ------------ ---------------------------- ---------------------
  主要作用     指定响应形式                 规定响应数据结构
  关注的问题   返回什么格式                 返回什么数据
  常见参数值   HTMLResponse、FileResponse   Pydantic 模型
  典型用途     返回网页、文件               规范 API 返回的数据

### 记忆方法

``` text
response_class
       ↓
响应的形式是什么？
       ↓
HTML / 文件 / 纯文本等


response_model
       ↓
响应的数据应该是什么结构？
       ↓
id: int
name: str
content: str
```

### 特别注意：不能混用

错误写法：

``` python
@app.get("/html", response_model=HTMLResponse)
async def get_html():
    return "<h1>Hello World</h1>"
```

原因：

`HTMLResponse` 是响应类，不是用来定义数据字段的 Pydantic 模型。

正确写法：

``` python
@app.get("/html", response_class=HTMLResponse)
async def get_html():
    return "<h1>Hello World</h1>"
```

## 5. 本章常见响应类

  响应类                作用         使用场景
  --------------------- ------------ ---------------------
  `JSONResponse`        返回 JSON    API 数据接口
  `HTMLResponse`        返回 HTML    网页页面
  `PlainTextResponse`   返回纯文本   普通文字
  `FileResponse`        返回文件     图片、PDF、Excel 等
  `RedirectResponse`    重定向       跳转到其他网址
  `StreamingResponse`   流式响应     流式数据、大文件等

示例：

``` python
from fastapi.responses import (
    JSONResponse,
    HTMLResponse,
    PlainTextResponse
)

# JSON
return JSONResponse({"name": "Yui"})

# HTML
return HTMLResponse("<h1>Hello</h1>")

# 纯文本
return PlainTextResponse("Hello World")
```

## 6. 易错点与排查

### 6.1 路由地址必须对应

例如：

``` python
@app.get("/html", response_class=HTMLResponse)
```

浏览器应访问：

``` text
http://127.0.0.1:8000/html
```

注意：路由路径区分大小写，`/html` 和 `/HTML` 不是同一个路径。

### 6.2 404 Not Found

``` json
{"detail": "Not Found"}
```

通常表示没有匹配到对应的路由。

排查：

-   浏览器访问路径是否与装饰器中的路径一致？
-   路由是否成功注册？
-   Uvicorn 是否正在运行？
-   修改代码后，服务器是否已经重新加载完成？

可以打开：

``` text
http://127.0.0.1:8000/docs
```

检查接口是否出现在自动生成的接口文档中。

### 6.3 FileResponse 找不到文件

检查：

-   文件是否真实存在？
-   路径是否正确？
-   相对路径是相对于当前工作目录，而不一定是 `main.py` 所在目录。
-   是否误把浏览器 URL 当成了本地文件路径？

### 6.4 Invalid args for response field

如果出现类似：

``` text
Invalid args for response field!
```

检查是否把响应类错误地写进了 `response_model`。

例如：

``` python
# 错误
response_model=HTMLResponse

# 正确
response_class=HTMLResponse
```

## 7. 考前速记：本章总结

``` text
FastAPI 响应
│
├── 默认响应
│   └── Python 字典、列表等 → JSON
│
├── 设置响应形式：response_class
│   ├── HTMLResponse      → HTML 页面
│   ├── FileResponse      → 文件
│   ├── JSONResponse      → JSON
│   ├── PlainTextResponse → 纯文本
│   ├── RedirectResponse  → 重定向
│   └── StreamingResponse → 流式响应
│
└── 设置响应数据结构：response_model
    ├── 使用 Pydantic BaseModel
    ├── 验证响应数据
    ├── 处理数据类型
    ├── 过滤未声明字段
    └── 生成接口文档
```

**一句话记忆：**

-   `response_class`：决定以什么形式返回。
-   `response_model`：决定返回的数据应该符合什么结构。
-   `HTMLResponse`：返回网页。
-   `FileResponse`：返回文件。
-   `BaseModel`：定义数据模型。
