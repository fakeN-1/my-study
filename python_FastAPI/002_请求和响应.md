# 请求和响应
- 响应的格式为python 的时候FastAPI能够自动转换为JSON的格式.
> 另外FastAPI还支持其他的类型
### 设置响应类型
- 在装饰器中设置
- HTMLResponse:用于返回html格式文件
```python
from fastapi.responses import HTMLResponse
@app.get("/html", response_class=HTMLResponse)
async def get_html():
    return "<h1>Hello World</h1>"
```
- 这样就能够响应html的类型

- FileResponse: 用于返回图片,pdf,Excel等文件的格式
```
from fastapi.responses import FileResponse
@app.get("/file")
async def get_file():
    path="/files/1.jpeg"
    return FileResponse(path)
```
- 这样就能够通过FileResponse响应一张图片.

-自定义响应数据类型
- response_model
```
from pydantic import BaseModel
class News(BaseModel):
    id: int
    name: str
    content:str
@app.get("/news/{id}",response_model=News)
async def get_news(id: int):
    return {"id":id,
            "name":f"这是来自于{id}的书",
            "content":"这是一本好书"
            }
```
