# Python 虚拟环境与终端指令

## 一、虚拟环境（Virtual Environment）

### 1. 什么是虚拟环境？

- 虚拟环境是 Python 提供的一种独立运行环境。
- 每个项目可以拥有自己独立的 Python 第三方库，不会与其他项目产生依赖冲突。
- 例如：FastAPI 项目和爬虫项目可以分别安装不同版本的第三方库。

**核心理解：一个项目对应一个独立的虚拟环境。**

### 2. 创建虚拟环境

在 VS Code 终端（PowerShell）中操作。

**第一步：进入项目目录**

```powershell
cd D:\FastAPI\bilibili_book
```

**第二步：创建虚拟环境**

```powershell
python -m venv .venv
```

- `python`：调用 Python。
- `-m venv`：使用 Python 自带的 venv 模块。
- `.venv`：虚拟环境文件夹名称。

**第三步：激活虚拟环境**

```powershell
.\.venv\Scripts\Activate.ps1
```

激活成功后，终端前面会出现：

```text
(.venv) PS D:\FastAPI\bilibili_book>
```

**第四步：退出虚拟环境**

```powershell
deactivate
```

退出后，终端前面的 `(.venv)` 消失。

## 二、常用终端指令

以下主要针对 Windows PowerShell。

### 1. 虚拟环境操作

| 功能 | 指令 |
|---|---|
| 创建虚拟环境 | `python -m venv .venv` |
| 激活虚拟环境 | `.\.venv\Scripts\Activate.ps1` |
| 退出虚拟环境 | `deactivate` |

### 2. Python 相关指令

| 功能 | 指令 |
|---|---|
| 查看 Python 版本 | `python --version` |
| 查看 Python 路径 | `where.exe python` |
| 查看 pip 版本 | `python -m pip --version` |

### 3. 第三方库管理

| 功能 | 指令 |
|---|---|
| 安装库 | `python -m pip install 库名` |
| 卸载库 | `python -m pip uninstall 库名` |
| 更新库 | `python -m pip install --upgrade 库名` |
| 查看所有已安装库 | `python -m pip list` |
| 查看指定库的信息 | `python -m pip show 库名` |

### 4. FastAPI 安装步骤

**第一步：创建并激活虚拟环境**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**第二步：安装 FastAPI**

```powershell
python -m pip install "fastapi[standard]"
```

说明：
- `fastapi`：FastAPI 核心框架。
- `[standard]`：安装推荐的标准依赖，包括运行命令行工具所需的依赖。

**第三步：检查是否安装成功**

查看安装信息：

```powershell
python -m pip show fastapi
```

查看版本：

```powershell
python -c "import fastapi; print(fastapi.__version__)"
```

如果能够正常输出版本号，说明 FastAPI 可以正常导入。

**第四步：检查 FastAPI 命令**

```powershell
fastapi --version
```

能够正常输出版本信息，说明命令行工具也可以正常使用。

### 5. 依赖管理

将当前虚拟环境中安装的第三方库导出到文件：

```powershell
python -m pip freeze > requirements.txt
```

根据依赖文件安装第三方库：

```powershell
python -m pip install -r requirements.txt
```

这样可以方便地在其他电脑或环境中恢复项目依赖。
