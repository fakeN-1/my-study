# 请求体
- 当需要给制作的api发送信息的时候,就会以请求体的形式发送
- 请求体:发送给api的数据
- 响应体:api返回的数据

发送数据的(常见)关键字:
- POST:创建数据
- PUT:更新数据
- FELETE:删除数据
> 常见的GET是获取数据的方式,但也能够用于发送数据.

## Pydantic的BaseModel
- 这是一个数据模板的组件
- 可以(创建类)用于定义和管理数据结构,验证数据

导入BaseModel:
- `from pydantic import BaseModel`

创建数据模型
```python
from fastapi import FastAPI
from pydantic import BaseModel


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


app = FastAPI()


@app.post("/items/")
async def create_item(item: Item):
    return item
```
- 以上就是用了BaseModel声名了所有属性
- 其中` None = None`表示可选并且有默认值:None
- 而` price: float`是必选的,没有默认数值
- 如果参数属性类型不符合要求会出现` 422 `报错

## 请求体➕路径参数
- 同时使用请求体和路径参数
```python
from fastapi import FastAPI
from pydantic import BaseModel


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


app = FastAPI()


@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item):
    return {"item_id": item_id, **item.model_dump()}
```
- `item_id: int, item: Item`前面为路径参数,后面为请求体
- `**item.model_dump()` 这里把item变成字典后再解包
- 最后会输出多个键值对的字典

## 请求体 + 路径 + 查询参数

```python
from fastapi import FastAPI
from pydantic import BaseModel


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


app = FastAPI()


@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item, q: str | None = None):
    result = {"item_id": item_id, **item.model_dump()}
    if q:
        result.update({"q": q})
    return result
```
