# 查询参数限制

## 1. 选择其中之一的参数
> order_by: Literal["created_at", "updated_at"] = "created_at"
- 上面的参数order_by的数值只能够选择:
- 1. created_at
  2. updated_at
- 这两个中括号中的其中之一
- 而默认的参数为最后的`created_at`


## 2. 静止额外的查询参数
```python
from typing import Annotated, Literal

from fastapi import FastAPI, Query
from pydantic import BaseModel, Field

app = FastAPI()


class FilterParams(BaseModel):
    model_config = {"extra": "forbid"}

    limit: int = Field(100, gt=0, le=100)
    offset: int = Field(0, ge=0)
    order_by: Literal["created_at", "updated_at"] = "created_at"
    tags: list[str] = []


@app.get("/items/")
async def read_items(filter_query: Annotated[FilterParams, Query()]):
    return filter_query
```
在以上的代码中,有一段:
>  model_config = {"extra": "forbid"}
- 这个就表示:**用户传递的数据，必须符合我定义的字段要求，不能随意添加其他字段。**
- 也就是说,如果上传FilterParams中没有的数据,就会422报错


## 3. 组合参数模型
- 也就是声明多个查询参数,并且将他们混合使用.

比如:
```python
from typing import Annotated

from fastapi import FastAPI, Query
from pydantic import BaseModel, Field

app = FastAPI()


class Pagination(BaseModel):
    limit: int = Field(10, ge=1)
    offset: int = Field(0, ge=0)


class Filters(BaseModel):
    tags: list[str] = []


@app.get("/items/")
def read_items(
    pagination: Annotated[Pagination, Query()],
    filters: Annotated[Filters, Query()],
    search: str | None = None,
):
    return {"pagination": pagination, "filters": filters, "search": search}
```
- 以上就声明了两个查询参数模型
- 并且在函数中调用返回
  
## 4.可选查询参数模型
- 在限制的时候,使用`|None`就可以将这组参数设置为可选.

举例:
```python
from datetime import date
from typing import Annotated

from fastapi import FastAPI, Query
from pydantic import BaseModel

app = FastAPI()


class DateRange(BaseModel):
    start: date
    end: date


@app.get("/items/")
async def read_items(
    limit: int = 10,
    date_range: Annotated[DateRange | None, Query()] = None,
):
    return {"limit": limit, "date_range": date_range}
```
- 这里面`date_range: Annotated[DateRange | None, Query()] = None,`
- 就是可选的查询参数
- 选择的范围是DateRange的范围内,默认值为None
- 或者直接不选择.
