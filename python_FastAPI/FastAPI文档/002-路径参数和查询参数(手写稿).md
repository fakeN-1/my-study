# 路径参数
这类参数可以直接在URL中显示出来
- 制作一个简单的路径参数展示:
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/item/{item_id}")
async def id(item_id: str):
    return {"id": item_id}
```
- 路径参数能够把URL中的数值传递给函数作为参数使用
- 运行访问`http://127.0.0.1:8000/item/小恩`
- 会吧**小恩**作为参数

### 路径参数的声名
- 这里的` item_id: str`
- 把输入的参数声名为了一个字符串类型
- 后面还会使用更加复杂的声名,使用更复杂的关键字.

当声名的参数不符合的时候,会返回报错
> <img width="618" height="286" alt="image" src="https://github.com/user-attachments/assets/a88d2d1b-3dfd-40ad-b6fd-839e899a8638" />
- 这里我把参数修改为int类型
- 报错显示输入必须为有效的整数，无法将字符串解析为整数。
- 而""小恩"不是整数类型

### 顺序
- 为了确保不会访问错误
- 一般会先声名已经确定的路径

比如:
```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/users/me")
async def read_user_me():
    return {"user_id": "the current user"}


@app.get("/users/{user_id}")
async def read_user(user_id: str):
    return {"user_id": user_id}
```
- 在以上的代码里:
- 先声名了/user/me
- 再声名/user/{user_id}
- 这就是为了访问的时候不会出错.

同样,也不能重复定义一个路径
- 就比如定义两个`@app.get("/users/me")`

# 查询参数
- 当参数不参与URL中的时候,会被自动解释为查询参数

也就是:
```python
from fastapi import FastAPI

app = FastAPI()

fake_items_db = [{"item_name": "Foo"}, {"item_name": "Bar"}, {"item_name": "Baz"}]


@app.get("/items/")
async def read_item(skip: int = 0, limit: int = 10):
    return fake_items_db[skip : skip + limit]
```
这里面的`skip`和`limit`就是查询参数
- 查询字符串是键值对的集合,这些键值对位于URL的?,使用&分隔.

比如:
> http://127.0.0.1:8000/items/?skip=0&limit=10
- 这里表示查询参数:
- skil=0
- limit=10
- 而以上的数值也就这两个查询参数的默认值

>http://127.0.0.1:8000/items/?skip=20
- 这样就是访问skip的设定值
- skip=20


### 查询参数类型转换
- 代码:`async def read_item(item_id: str, q: str | None = None, short: bool = False):`
- 这里面的最后short: bool=false
- short 的默认数值为false
- 而在URL中访问:
> http://127.0.0.1:8000/items/foo?short=1
---
> http://127.0.0.1:8000/items/foo?short=on
---
> http://127.0.0.1:8000/items/foo?short=yes
- 类似以上代码的时候,short的数值都将为Trun

###  多个路径
- 同时声名多个路径
- 类似于:`@app.get("/users/{user_id}/items/{item_id}")`

### 必选查询参数
- 如果不设置默认值,就会变成必选值
`@app.get("/items/{item_id}")
async def read_user_item(item_id: str, needy: str):`
- 以上的item_id和needy都是必选的查询参数
