<h3>伪类选择器</h3>
伪类选择器:用来选中处于某种状态或符合某种条件的元素<br>
例如，鼠标移到按钮上时改变它的颜色：

```
.button{
background-color: #4CAF50; /* Green */
border: 1px solid #4CAF50;
}
button:hover {
  background-color: dodgerblue;
}
```

<h3>常用伪类元素</h3>
1.hover：鼠标悬停

```
a:hover {
  color: orange;
}
```
<br><hr><br>
2.active:正在按下或激活

```
button:active {
  transform: scale(0.97);
}
```
3.:link:匹配尚未访问的链接
4.visited:匹配已访问的链接
<br><hr><br>
<h3>结构类的伪类元素</h3>
1.first-child:父元素的第一个子元素<br>
2.last-child:父元素的最后一个子元素<br>
3.only-child:唯一的子元素<br>
4.nth-child():按照位置选择子元素<br>

```
li:nth-child(odd)  { background: #f5f5f5; }
li:nth-child(even) { background: white; }
li:nth-child(3n)   { color: purple; }
```
5.nth-last-chilid():从末尾开始数<br>
6.nth-of-type()按照同类型元素选择<br>
<br><hr><br>
<h3>一个实例</h3>

```<ul class="menu">
  <li><a href="#">首页</a></li>
  <li><a href="#">课程</a></li>
  <li><a href="#">关于</a></li>
</ul>

<input class="email" type="email" required>
```
```
.menu {
  display: flex;
  gap: 16px;
  list-style: none;
  padding: 0;
}

.menu li:first-child a {
  font-weight: bold;
}

.menu li:nth-child(even) {
  background: #f2f6ff;
}

.menu a:hover,
.menu a:focus-visible {
  color: #2563eb;
  text-decoration: underline;
}

.email:focus {
  outline: 2px solid #93c5fd;
}

.email:invalid {
  border: 1px solid #dc2626;
}

.email:valid {
  border: 1px solid #16a34a;
}
```

<br>
:first-child 选第一个菜单项；
:nth-child(even) 选偶数位置的菜单项；
:hover 处理鼠标悬停状态；
:focus-visible 提供键盘焦点提示；
:focus 处理输入框当前焦点；
:invalid 和 :valid 根据表单校验状态设置样式。
