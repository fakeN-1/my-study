<h3>网格布局</h3>
网格布局（CSS Grid）是一种二维布局方式：可以同时控制行和列<br>
建立网格容器:先给父元素设置 <strong> display: grid  </strong>          <br>

```
<div class="grid">
  <div class="item">卡片 1</div>
  <div class="item">卡片 2</div>
  <div class="item">卡片 3</div>
  <div class="item">卡片 4</div>
</div>
```
```
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr; /* 两列，平均分配剩余空间 */
  gap: 16px;                      /* 行和列之间的间距 */
}
.item{
  border: 2px solid #2e5561;
}
```

<h5>repect函数:重复</h5>

```
.grid{
  display:grid;
  /* grid-template-columns:1fr 1.5fr 1fr; */
  grid-template-rows:repeat(5,1fr) repeat(1,3fr);
  gap:20px
}
```

<h3>命名区域:grid-template-areas</h3>

```
<div class="page">
  <header>页头</header>
  <nav>导航</nav>
  <main>正文</main>
  <aside>侧栏</aside>
  <footer>页脚</footer>
</div>
```



```
.page {
  display: grid;
  grid-template-columns: 180px 1fr 220px;
  grid-template-areas:
    "header header header"
    "nav    main   aside"
    "footer footer footer";
  gap: 12px;
}

header { grid-area: header; }
nav    { grid-area: nav; }
main   { grid-area: main; }
aside  { grid-area: aside; }
footer { grid-area: footer; }

```

<h3>显式网格和隐式网格</h3>
显式网格是你用 CSS 明确创建的行和列；隐式网格是项目超出显式网格后，浏览器为它们自动补出来的行或列。<br>
用 grid-auto-rows 和 grid-auto-columns 控制浏览器自动创建的行或列<br>

```
.grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr); /* 显式两列 */
  grid-template-rows: 100px 100px;             /* 显式一行 */
  grid-auto-rows: 200px;               /* 新增的隐式行高为 80px */
  gap: 10px;
}
.grid>div{
  border: 1px solid #000;
}
```
