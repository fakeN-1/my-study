 <h3>嵌套选择器</h3>
 允许一个选择器嵌套在另一个选择器的大括号中,并且与外层选择器有关联.
<br>
传统写法:

```
.card {
  padding: 16px;
}

.card h2 {
  margin-top: 0;
}

.card a:hover {
  color: royalblue;
}
```
使用嵌套选择器,可以把相关规则嵌套在一起:

```
.card {
  oadding:16px;
  h2{
    margin-top:0;
  }
  a:hover{
    color:royalblue;
  }
}
```
会更加简便并且方便修改.
<br><hr><br>
<h3>1.后代选择器嵌套</h3>
在外层选择器的大括号内部直接写另一个选择器,默认表示后代的关系:

```.card {
  .title {
    color: #222;
  }

  p {
    line-height: 1.6;
  }
}
```
大致等价于:

```
.card .title {
  color: #222;
}

.card p {
  line-height: 1.6;
}
```
<br><hr><br>
<h3>2.&：引用外层选择器</h3>
给父类元素增加伪类

```
.button {
  background: royalblue;

  &:hover {
    background: navy;
  }

  &:focus-visible {
    outline: 3px solid lightblue;
  }
}
```
等价于:
```
.button {
  background: royalblue;
}

.button:hover {
  background: navy;
}

.button:focus-visible {
  outline: 3px solid lightblue;
}
```
同时,与修饰类的组合:

```
.button {
  &.primary {
    background: royalblue;
  }

  &.danger {
    background: crimson;
  }
}
```
等价于
```
.button.primary { ... }
.button.danger { ... }
```
注意，&.primary 表示同一个元素同时拥有两个类名。它和 .button .primary 不一样，后者表示 .button 里面有一个 .primary 后代。
