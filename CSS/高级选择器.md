<h3>后代选择器</h3>
用空格间隔:选择后代的元素

```HTML
<div  class="content1" >
    这是一段文本
    <div>
        这是内部的文本
        <div>这是内部的内部文本</div>
    </div>
</div>
```

```CSS
.content1 div{
    color: red;
}
```

<h3>选择器的优先级</h3>
CSS 选择器优先级（Specificity）可以按 (a, b, c) 三列来比较，从左到右逐列比较：先比 a，相同再比 b，再比 c。某一列更大，优先级就更高。
<br>
 a:ID 选择器，如 `#title`
 b:类、属性、伪类，如 `.card`、`[disabled]`、`:hover` 
 c:标签、伪元素，如 `div`、`::before` 
 通用选择器 `*`、组合符（空格、`>`、`+`、`~`） 

 ```CSS
#content_id{color: blue;}
.content{color: rgb(136, 255, 0);}
div{color: red;}
```

<h3>CSS样式的继承</h3>
某些属性会从父元素传递给子元素，所以不用给每个子元素重复设置

```
<div >
   <div>这是一段文字</div>
   <p>这是一个段落</p>
</div>
```

```
div{
    color:rgb(255, 94, 0);
    font-family: "微软雅黑";
}
```

<br>
常见的继承:常见可继承属性主要与文字显示有关：<br>
- color
- font-family
- font-size
- font-style
- font-weight
- line-height
- text-align
- visibility
- cursor
<br>很多布局和盒模型属性默认不会继承，例如：<br>
- width、`height`
- margin、`padding`
- border
- background
- display
- position
