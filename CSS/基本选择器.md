<h3>class选择器</h3>
使用class属性给元素分类,就可以固定改变元素的样式<br>
使用.在css中引用class

```
<div class="content">
    这是一段文本
</div>
```

```
.content{
    /* size: 100px; */
    color: rgb(32, 165, 72);
}
```

<h3>id选择器</h3>
与class选择器相同,但是id选择器是全局唯一的,不能重复,并且不能和class标签同名.<br>
使用#可以在css中引用id<br>
id选择器的优先级高于class
<img width="652" height="643" alt="image" src="https://github.com/user-attachments/assets/cba6a006-c953-4846-b000-0b2c2c250861" />
<img width="843" height="123" alt="image" src="https://github.com/user-attachments/assets/068a4ec2-615e-4683-9e95-f37a1aafb213" />

```css
#container{
    color: rgb(165, 103, 32);
    /* 修改文本的颜色 */
}
```

<h3>通配符选择器*</h3>
一次性选择所有的元素

```
*{
    color: rgb(165, 32, 32);
}
```

<h3>交集选择器</h3>

```HTMl
<div  class="content1" >
    这是一段文本
</div>
<div  class="content2"  >
    这是二段文本
</div>
<div  class="content3"  >
    这是三段文本
</div>
<div  class="content3"  id="container"  >
    这是三段文本,并且我有唯一的id
</div>
```

```CSS
div.content3{
    color: rgb(32, 165, 72);
}
div.content3#container{
    color: rgb(82, 4, 65);
}
```

<h3>并集选择器</h3>
使用逗号分开可以达到并集的效果<br>
以下的两个代码表达的含义相同<br>

```CSS
p{
    color: #000;
}
div{
    color: #000;
}
.content{
    color: #000;
}
#container{
    color: #000;
}
```
<hr>

```
p,div,.content,#container{
    color: #000;
}
```
