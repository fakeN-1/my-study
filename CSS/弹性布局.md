<h3>弹性布局</h3>
Flex 布局（Flexible Box Layout，弹性盒子布局）是一种<strong>一维布局</strong>方式：它沿着一个方向排列元素，并帮助这些元素分配空间、对齐位置、换行或伸缩。<br>
弹性布局主要由两个部分组成:<br>
Flex容器:设置了display:flex或者display:inline-flex的元素.<br>
Flex项目:Flex容器的直接子元素.

```
<div class="container">
  <div class="item">
    <span>苹果</span>
  </div>
</div>
```
```
.container {
  display: flex;
}
```
在这里外层的cintainer和内层的item都是flex项目,而最内层的span并不是flex项目.
<br><hr><br>
<h5>主轴和交叉轴</h5>
主轴:flex项目的排列方向<br>
交叉轴:与主轴垂直的方向<br>
默认主轴为水平方向<br>
justfy-content:水平排列<br>
align-item:垂直排列<br>
<br><hr><br>
<h3>相关的属性</h3>
<h5>flex-direction:设置主轴的方向</h5>

```
.container{
  display:flex;
  flex-direction:row;
}
```
flex-direction<br>
row	 横向主轴正向排列，默认值<br>
row-reverse	 主轴反向排列<br>
column 	纵向主轴排列<br>
column-reverse	 纵向主轴反向排列<br>
<br><hr><br>
<h5>flex-wrap</h5>
默认情况下，Flex 项目会尽量挤在一行或一列内。<br>

```
.container {
  display: flex;
  flex-wrap: wrap;
}
```
nowrap   	不换行，默认值<br>
wrap	  空间不足时换行<br>
wrap-reverse	  换行，但新行沿交叉轴反向排列<br>
<br><hr><br>
<h5>flex-flow:方向和换行的简写</h5>
flex-flow 是 flex-direction 和 flex-wrap 的简写：<br>

```
.container {
  display: flex;
  flex-flow: row wrap;
}
```
表示水平正向并且需要换行,也等价于:

```
.container {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap;
}
```
<br><hr><br>
<h5>justify-content:沿主轴排列项目</h5>

```
.container {
  display: flex;
  justify-content: center;
}
```
flex-start	项目靠主轴起点排列，默认值<br>
flex-end	项目靠主轴终点排列<br>
center	项目整体居中<br>
space-between	首尾项目贴近两端，剩余空间分配到项目之间<br>
space-around	每个项目两侧分配相等空间；外侧间距约为项目间距的一半<br>
space-evenly	项目之间和容器两端的间距相等<br>
<br><hr><br>
<h5>align-items:沿交叉轴对齐所有项目</h5>

```
.container {
  display: flex;
  align-items: center;
}
```
stretch	拉伸项目以填满交叉轴空间，默认值（受尺寸限制）
flex-start	对齐交叉轴起点
flex-end	对齐交叉轴终点
center	沿交叉轴居中
baseline	按项目中文字基线对齐
<br><hr><br>
<h5>
align-content：多行内容整体在交叉轴上的分布
</h5>

```
.container {
  display: flex;
  flex-wrap: wrap;
  align-content: space-between;
  height: 300px;
}
```
常见值:

```
align-content: flex-start;
align-content: flex-end;
align-content: center;
align-content: space-between;
align-content: space-around;
align-content: space-evenly;
align-content: stretch;
```
<br><hr><br>
<h5> gap:间距</h5>

```
.container {
  display: flex;
 gap: 20px 12px; /* 行间距 列间距 */
}
```
<br><hr><br>
<h3>flex 的项目属性:仅仅作用于子元素</h3>
<h5>order：改变视觉顺序</h5>
默认情况下，所有项目的 order 都是 0。数值较小的项目会排在前面：

```
.first {
  order: 1;
}

.second {
  order: -1;
}
```
<br><hr><br>
<h5>flex-grow,flex-shrink,flex-basis:扩展,收缩,基础尺寸</h5>
有多余空间时如何扩展,空间不足时如何收缩,伸缩前的基础尺寸<br>

```
flex-grow: 1;
flex-shrink: 0;
flex-basis: 200px;
```
简写:
```
flex:1 0 200px
```
