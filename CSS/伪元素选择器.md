<h3>伪元素选择器</h3>
伪元素选择器可以选中元素的某一部分，或在元素内容前后创建一个由 CSS 生成的内容位置。
它通常以双冒号 :: 开头：

```
选择器::伪元素 {
  属性: 值;
}
```
<br><hr><br>
<h3>伪类和伪元素的区别</h3>
伪类选择元素的某种状态<br>
伪元素选择的是元素中的一部分<br>

```
botton:hover{
color:blue; /* 按钮处于悬停状态 */
}
p::first-line{  /* 段落的第一行 */
font-weight:bold
}
```
<br><hr><br>
<h3>常用伪元素</h3>
<h3>::before在元素前生成内容</h3>

```
<p class="notice">资料已保存<p>
```
```
.notice::before{
content:"✔️";
color:green;
}
```
这表示在资料已保存的字体元素前面增加一个绿色的✔️
