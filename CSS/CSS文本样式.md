<h3>文本样式</h3>

```
.article {
  color: #333;                  /* 文字颜色 */
  text-align: left;             /* 对齐：left、center、right、justify */
  text-decoration: none;        /* 装饰线：underline、line-through 等 */
  text-transform: none;         /* 大小写转换：uppercase、lowercase、capitalize */
  text-indent: 2em;             /* 首行缩进 */
  letter-spacing: 0.05em;       /* 字符间距 */
  word-spacing: 0.1em;          /* 单词间距 */
  line-height: 1.7;              /* 行高 */
}
```

<hr>
<br>
<h5>对齐：text-align</h5>

```
    text-align:center; /* 中心对齐 */
    text-align: left; /* 左对齐 */
    text-align: right;/* 右对齐 */
```
