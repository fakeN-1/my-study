# vue基础
>如何配置打开一个vue工程
## 创建一个vue项目
- 在终端中输入:npm create vue@latest
><img width="989" height="512" alt="image" src="https://github.com/user-attachments/assets/58f6f9b1-ae44-4022-8e3b-f2f023e7a08d" />
- 接着输入项目名称等设置
## 在终端中再次打开vue项目
- 在父文件夹上输入:npm run dev
- 默认是在本地创建一个网址:http://localhost:5173/
