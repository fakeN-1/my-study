# 函数
### 函数的变量作用域
- 函数的作用范围,主要分为**全局变量**和**局部变量**两类
- 全局变量:在函数之外定义.
- 局部变量:在函数之内定义.(只能在函数的内部使用和调用)
```python
num=1
def fun():
    global num
    num=100
    print(num) #100
fun()
print(num) #100
```
-galobal关键字:只调用全局变量,这样就能够在函数内部修改变量的数值

### 函数的参数
函数的传参方式
- 1.位置参数:函数按照定义时候的位置进行传递参数,顺序和定义时完全一致.
- 2.关键字参数:按照键值对的形式进行参数的传递.
``` python
def reg_stu(name, age, sex, grade):
     print("姓名：", name)
     print("年龄：", age)
     print("性别：", sex)
     print("年级：", grade)
     print("")
reg_stu(age=18, sex="男", name="张三", grade="10")
```
> 1和2的参数传递可以混用,但是需要先写位置参数.
默认参数
> 参数可以设置默认值.
> 默认值需要放置在形参的最后.
```python
def reg_stu(name, age, sex, grade="一年级"):
```
不定长参数
- 基于位置传递的不定长参数
- def fun(*args) :这样就args就可以传递多个数据的参数
> args的类型是元组(args只是给命名,但是约定使用args)
例题:需求:定义函数，根据传入的数据，计算这批数据中的最小值、最大值、平均值。
```python
def calc_data(*args):
    """
    :param args: 传入的参数
    :return: 返回最小值，最大值，平均值
    """
    min_data=min(args)
    max_data=max(args)
    avg_data=sum(args)/len(args)
    return min_data,max_data,round(avg_data,1)
print(calc_data(1,2,37,42,5.1))
```
- 不定长参数-关键字传递(**kwargs)
- def fun(**kwargs)
- 最终kwargs的类型是一个字典.

### 参数的类型
- 普通参数:比如数字,布尔,字符串,元组等等都是普通参数
- 特殊参数:函数.
```
def add(x,y):
     return x+y
def  sub(x,y):
      return x-y
def calc(x,y,oper):
      return oper(x,y)
print(calc(1,2,add))
```
> 此时 oper这个形参调用的就是函数(前面的add()和sub()函数).

# 匿名函数
- 使用** def **关键字调用的函数是 命名函数
- 使用** lambda **关键词定义的函数为 匿名函数
### 匿名函数的定义
- 匿名函数适用于逻辑简单,只使用到一个地方
- lambda x,y:print(x+y) ->这就是一个简单的匿名函数
> 其中的xy为参数,
> 匿名函数的结果会自动返回

-例题:排序
```
data_list = ["C++", "C","Python","Jack","PHP","Java","Javascript","G0","Rust"]
data_list.sort(key=lambda item: len(item))
print("排序后的列表：",data_list)
```
> .sort用法是控制列表中的函数的排序.
- 例题2:计算数字的阶乘
```
# 定义一个函数，根据传入的数字，计算该数字阶乘的结果
def fun(num):
     # 判断传入的参数是否为数字类型
     if type(num) == int:
         # 如果是数字类型，计算阶乘结果
         result = 1
         for i in range(1, num + 1):
             result *= i
         # 返回计算结果
         return result
     else:
         # 如果不是数字类型，返回错误信息
         return "输入的参数必须为数字类型！"

# 调用函数，计算10的阶乘结果
result = fun(10)
```
方法2:递归调用

def jc(n):
    if n == 1:
        return 1
    else:
        return n*jc(n-1)
result=jc(10)
