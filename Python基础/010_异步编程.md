# 异步编程
### 同步执行和异步并发
> 传统的同步执行在程序执行的过程中,需要等待输出/输入操作完成后在能够进行下一步.这大大降低了使用的整体效率,而异步编程就解决了这个痛点.

### asyncio-事件循环
- 当程序遇到I/O等待的时候,让程序切换执行为其他的任务.
- python的asynicio模块的事件循环能力实现这样的功能.
例子:
```python
import asyncio

async def fetch(name):
    print(f"开始请求 {name}")
    await asyncio.sleep(2)
    print(f"{name} 返回了")

async def main():
    await asyncio.gather(fetch("A"), fetch("B"), fetch("C"))

asyncio.run(main())
```
- async def:定义一个异步函数(协程函数)
- await : 等待一个异步操作,如果它还没有完成,就会暂停当前任务,让其他任务执行.
- asyncio.gather() : 让多个线程并发运行.
- asyncio.run() : 在普通脚本里启动异步程序.
