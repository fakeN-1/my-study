# 面向对象基础
- 面向对象:把对象(人/物)的属性和功能(方法)打包到一起,这就是面向对象编程的基本单元.
>之前使用的是面向过程:也就是把需求分解为一系列需要执行的步骤.
### 类与对象
- 属性:描述相同属性和方法的模板
- 对象:万事万物皆为对象.对象是基于类的实例,是基于类创建出来的(实例对象).
### 类的定义
```python
# 定义类
class 类名:
  pass
# 创建对象
对象名=类名()
对象名.属性名=属性1
```
> 类名的命名规范一般首字母大写,例如:UserIofo,UserAccount(大驼峰命名法)
- .__dict__这个方法能够吧对象以字典的形式输出
```python
class Car:
    pass
c1=Car()
c1.color="red"
c1.name="X5"
c1.brand="BMW"
print(c1.__dict__)
```

### 类的定义的标准
```python
class 类名:
  def ___init__(self,参数列表):
    self.属性名1=参数值
    self.属性名2=参数值
#创建对象
对象名=类名(参数列表)
```
> 这里面的self代表的是创建的实例对象
-具体案例展示:
```
#创建类(类是一个模板)
class Car:
    def __init__(self,c_color,c_brand,c_name,c_price):
        self.c_color=c_color
        self.c_brand=c_brand
        self.c_name=c_name
        self.c_price=c_price
#创建对象
car=Car("red","BWM","X7",800000)
print(car.__dict__) 
# 输出一个字典:
# {'c_color': 'red', 'c_brand': 'BWM', 'c_model': 'X7', 'c_price': 800000}
```
> 里面的__init__是一个初始化的方法,用于设置类的属性的初始状态.

### 实例方法
- 实例方法的定义和函数的定义是一致的
><img width="424" height="224" alt="image" src="https://github.com/user-attachments/assets/89ba4e79-ac65-4422-8cf3-28c04e90290c" />
- 案例
 ```python
  class Car:
    def __init__(self,c_color,c_brand,c_name,c_price):
        self.c_color=c_color
        self.c_brand=c_brand
        self.c_name=c_name
        self.c_price=c_price
#  定义方法
    def running(self):
        print(f"{self.c_brand}-{self.c_name}正在高速行驶.")
    def total_price(self,discount,rate):
        """
        discount:折扣
        rate:税率
        """
        total_cost=self.c_price*rate+self.c_price*discount
        return total_cost
# 创建实例
c1=Car("red","BYD","Tang",200000)
c1.running()
print(c1.total_price(0.95,0.08))
```
>这样就定义了类的方法

### 魔法方法
- 魔法方法:简单来说就是用"__"开头和结尾的方法
- 这种方法python解释器可以自动调用
-常见魔法方法:
><img width="1022" height="282" alt="image" src="https://github.com/user-attachments/assets/62c23b6e-54dc-4b43-a3f7-fce428872ad1" />
-自动调用:
>比如:当在类中创建了字符串的魔法方法,类似def __str__(self):return 一些数据,这样的话,当创建实例输出的时候,不用使用__str__,而是直接print(实例名称),就能够自动输出字符串格式的数据.类似的还有__lt__比大小这样的.
- 例子:
```
class Car:
    def __init__(self,c_color,c_brand,c_name,c_price):
        self.c_color=c_color
        self.c_brand=c_brand
        self.c_name=c_name
        self.c_price=c_price
#  定义方法
    def running(self):
        print(f"{self.c_brand}-{self.c_name}正在高速行驶.")
    def total_price(self,discount,rate):
        """
        discount:折扣
        rate:税率
        """
        total_cost=self.c_price*rate+self.c_price*discount
        return total_cost
    def __str__(self):
        return f"{self.c_color},{self.c_brand},{self.c_name},{self.c_price}"
# 创建实例
c1=Car("red","BYD","Tang",200000)
print(c1)
#red,BYD,Tang,200000
```

### 实例属性和类属性
- 属性分为两种
- 实例属性: 实例属性属于每个对象特有的属性,每个对象都是独立的.
- 类属性:类属性属于类本身的属性,所有实例共享的.
><img width="1581" height="650" alt="image" src="https://github.com/user-attachments/assets/9bee969b-f6bf-4e55-aeeb-4de458e907f6" />
- 实例和类属性的定义:
```python
class Car:
    wheel=4 #轮胎的个数
    tax_rate=0.1 # 汇率
    def __init__(self,c_color,c_brand,c_name,c_price):
        self.c_color=c_color
        self.c_brand=c_brand
        self.c_name=c_name
        self.c_price=c_price
```
>通过实例对象,查找属性的时候会先实例属性,再查找类属性.
