# 面向对象基础
- 面向对象:把对象(人/物)的属性和功能(方法)打包到一起,这就是面向对象编程的基本单元.
>之前使用的是面向过程:也就是把需求分解为一系列需要执行的步骤.
### 类与对象
- 属性:描述相同属性和方法的模板
- 对象:万事万物皆为对象.对象是基于类的实例,是基于类创建出来的(实例对象).
### 类的定义
```python
# 定义类
class 类名:
  pass
# 创建对象
对象名=类名()
对象名.属性名=属性1
```
> 类名的命名规范一般首字母大写,例如:UserIofo,UserAccount(大驼峰命名法)
- .__dict__这个方法能够吧对象以字典的形式输出
```python
class Car:
    pass
c1=Car()
c1.color="red"
c1.name="X5"
c1.brand="BMW"
print(c1.__dict__)
```

### 类的定义的标准
```python
class 类名:
  def ___init__(self,参数列表):
    self.属性名1=参数值
    self.属性名2=参数值
#创建对象
对象名=类名(参数列表)
```
> 这里面的self代表的是创建的实例对象
-具体案例展示:
```
#创建类(类是一个模板)
class Car:
    def __init__(self,c_color,c_brand,c_name,c_price):
        self.c_color=c_color
        self.c_brand=c_brand
        self.c_model=c_name
        self.c_price=c_price
#创建对象
car=Car("red","BWM","X7",800000)
print(car.__dict__) 
# 输出一个字典:
# {'c_color': 'red', 'c_brand': 'BWM', 'c_model': 'X7', 'c_price': 800000}
```
