# if条件判断
### if基本格式
- if elif else
>要判断的条件成立,则执行以下的操作
```
s1=input("输入你的第一个爱好:")
s2=input("输入你的第二个爱好:")
s3=input("输入你的第三个爱好:")
s4=input("输入你的第四个爱好:")
print(f"你的爱好是{s1},{s2},{s3},{s4}")
if  s1=="唱" and s2=="跳" and s3=="rap" and s4=="篮球":
     print("小黑子,被我抓住鸡脚了吧!")
elif s1=="c" and s2=="t" and s3=="r" or s4=="l":
     print("不准黑我家鸽鸽")
elif s1==" " or s2=="" or s3==" " or s4==" ":
     pass
else:
     print("哎哟,你干嘛~")
```
> pass 空语句,仅仅有语法占位的作用.
# match 模式匹配
- match 条件匹配
```
day=input("请输入今天的日期：")
match day:
    case "1":
        print("今天是星期一")
    case "2":
        print("今天是星期二")
    case "3":
        print("今天是星期三")
    case "4":
        print("今天是星期四")
    case "5":
        print("今天是星期五")
    case "6" | "7":
        print("今天是周末")
    case _: 
        print("输入的日期不对") 
```
>以上的案例是用于匹配变量day的值
>注意:case后面直接加字符串,不加其他符号.


### 例题
```
num_1=float(input("请输入第一个数字:"))
num_2=float(input("请输入第二个数字:"))
oper=float(input("请输入运算符:"))

match oper:
    case "+":
        print(f"加法:{num1}+{num2}={num_1+num_2}")
    case "-":
        print(f"减法:{num1}-{num2}={num_1-num_2}")
    case "*":   
        print(f"乘法:{num1}*{num2}={num_1*num_2}")
    case "/" if num_2!=0:
        print(f"除法:{num1}/{num2}={num_1/num_2}")
    case _:
        print("输入的运算符有误")
```

### for 循环
- for循环本质是轮询遍历机制,对一批的内容进行逐个处理.
> 也就是不能确定循环的次数(这是和while的区别)
### 基本结构:
<img width="509" height="139" alt="image" src="https://github.com/user-attachments/assets/bd0ac072-2286-4478-88e7-f2935619d815" />

```
i="python"
for n in i:
     print(n)    
else:
      print("循环结束")
```
> 变量i为需要遍历的数据

- range(strat,end,step)函数:里面有三个数据
> 三个数据分别为开始,结束,步长.

```python
#计算1-101的奇数之和
sum=0
for i in range(1,101):
     if i%2!=0:
        sum+=i
else:
     print(f"一到一百的奇数之和为:{sum}")
```

### 嵌套循环
- 在循环中嵌套一共循环
><img width="553" height="290" alt="image" src="https://github.com/user-attachments/assets/545173f5-5f1b-4752-9b5c-b64c41f3f103" />
>技巧:先计算里面的循环,从内到外面读.
``` python
m = int(input("请输入正方形的边长："))

for i in range(m):
    for j in range(m):
        print("*", end=" ")
    print()
```
> 其中的end表示以=后的值结束,例题中为空格" " .
