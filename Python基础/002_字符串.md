### 字符串的格式化
- %s:可以把数据和字符串快速的拼接
```python
str1="爱好"
print( "你好,我 %s 是唱,跳,rap,篮球" %str1)
#你好,我 爱好 是唱,跳,rap,篮球
```

- f:通过f"内容{变量}"表示
```python
str1="爱好"
print( f"你好,我的 {str1} 是唱,跳,rap,篮球")
#你好,我的爱好 是唱,跳,rap,篮球
```
