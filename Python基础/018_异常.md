### 异常处理
- 不做处理
- 捕获异常:
关键词:try
> <img width="439" height="285" alt="image" src="https://github.com/user-attachments/assets/fac963f1-8a94-4623-8b53-352befb0ca31" />
```python
try:
  print("---------")
  print(name)
  print("---------")
except NameError as e:
  print("程序运行错误:",e)
finally:
  print("释放资源中...")
```
报错:name未被定义
<img width="324" height="44" alt="image" src="https://github.com/user-attachments/assets/2ed9aa91-eb60-47d3-993c-82b5fa3dc1d5" />

except关键字
>在上面的代码中,运行到print(name)的时候就会出现报错.
```
try:
  代码
except Exception as e
```
-这个就可以用于执行所有代码,用来检测异常.
