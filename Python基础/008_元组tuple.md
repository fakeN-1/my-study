# 元组
- 元组和列表一样都是用于贮存数据的容器
- 最大的不同是** 元组tuple不能修改 **
- 可重复 有序 不可修改
### 元组的定义
- 元组名称=(元素1,元素2)

### 元组的方法
- .count("python"):统计出现的次数
- .index("p"):查询第一次出现的位置

### 元组的组包和解包
- 组包:将多个值合并到一个容器中
- 解包:将容器解开为独立的元素,分配给多个变量
```
t1 = (1, 2, 3, 4, 5) #组包
a,b,c,d,e = t1       #解包
x,*y,z = t1          #扩展解包，*y表示y为一个列表
```
