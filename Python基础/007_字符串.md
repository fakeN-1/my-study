# 字符串 str
- 字符串是字符的容器
- 有序 不可以修改
### 字符串的常用方法
><img width="903" height="342" alt="image" src="https://github.com/user-attachments/assets/a02eb38f-b5ef-43eb-8d6c-d0a3f6d13e99" />
- .find("python"):返回第一次出现这个字符串的位置
- .count("python"):返回出现的字数
- .split(+):用指定符号分割为列表
- .strip("+"):两端的字符
- .replace("p","12"):替换
- .startswith("P"):检查是否为指定字符开头,并且返回布尔值.

### 例题
- 邮箱格式验证:用户输入一个邮箱，验证邮箱格式是否正确(包含一个@和至少一个.)
- 输出"邮箱格式正确"，否则输出"邮箱格式错误"。
```python
s=str(input("请输入邮箱的账号:"))
if s.count("@")!=1 or s.count(".")<1:
     print("邮箱格式不正确")
else:
      print("邮箱格式正确")
```
