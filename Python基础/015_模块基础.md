### 导入模块
- import关键字
> import random :表示调用随机数模块.
- 具体方式:
> <img width="958" height="395" alt="image" src="https://github.com/user-attachments/assets/d485e836-e348-4538-91f0-cb56425b57bd" />
-调用案例:
```python
import random as r
for i in range(10):
    print(r.randint(1, 100))
#随机输出十个数字,数字大小在1到100之间.
```
- 在python中使用全大写的命名规则去命名常量.

### 制作模块并导入
制作的模块
```python
#my_fun.py
PI=3.1415926
def log_PI():
    print("-"*20)
    print(PI)
    print("-"*20)
# log_PI()
```
```
import  my_fun

my_fun.log_PI()
```
>值得一提的是,在调用模块的时候会自动运行一次.
- 如果需要防止调用时自动运行,但是在模块中需要运行,则需要测试代码
- 测试代码:
```python
if __name__ =="__main__"
    log_PI()
```

### 导入全部功能
>from my_fun import *
-这个* 代表的导入的功能由__all__这个变量决定(如果模块中没有,则*代表全部功能)
><img width="981" height="414" alt="image" src="https://github.com/user-attachments/assets/78656fb2-a41a-4911-807c-a6f54461cdd6" />
```
#my_fun.py
__all__ = ['log_PI',"add"]
A=10
PI=3.1415926
def log_PI():
    print("-"*20)
    print(PI)
    print("-"*20)
def add():
     print(PI+PI)
def sub():
     print(A-PI)
     
if __name__ == '__main__':
     log_PI()
```
>以上的代码__all__中含有log_PI函数和add,则*调用的是log_PI()函数和add()函数
