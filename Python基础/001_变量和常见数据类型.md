### 基础数据类型
- int:整数.比如:10
- float:浮点数.比如:1.2
- str:字符串.比如:"你好"
- bool:布尔.包含false和True
- NoneType:空值.仅仅包含一个None

- 函数**type()**去产看变量的数据类型
```
base="hello"
print(type(base))  #str
```
><img width="998" height="383" alt="image" src="https://github.com/user-attachments/assets/88d717bd-a5c4-4eec-8b49-1a025241b01d" />
- 函数**isinstance()**检查数据类型是否为指定的类型
```python
base="hello"
print( isinstance(base, str))  # True
print( isinstance(base, int))  # False
```
