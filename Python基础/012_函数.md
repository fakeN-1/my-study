### 函数的参数和返回值
- 函数名后就是参数,函数的最后:return 返回值
><img width="325" height="238" alt="image" src="https://github.com/user-attachments/assets/f74f11a9-8dbb-4815-8903-ae1246dd6939" />
```python
#计算圆形的面积
def circle(r):
  area=3.14*r**2
  return area
print(circle(3))
```
- 其中的r为形式参数(形参),之后输入的3为实际参数(实参).
```python
#同时计算圆形的周长和面积
def circle(r):
     return round(3.14 * r * r,1),round(2 * 3.14 * r,1) #round表示保留小数
i=circle(5)
print(i)

area,perimeter=i #解包
print(area)
print(perimeter)
```
>round(数值,保留小数):这是一个内置的函数,表示保留几位小数

### 函数说明文档
- 函数的文档写在函数的开头
```
def circle(r):
     """
     计算圆的面积和周长
     :param r: 半径
     :return: 圆的面积和周长
     """
     return round(3.14 * r * r,1),round(2 * 3.14 * r,1) #round表示保留小数
i=circle(5)
print(i)
```
> 使用""" : """进行函数的注释说明
