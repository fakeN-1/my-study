### 使用lxml区域解析HTML
- lxml主要有两个作用:
1. 将HTML/XML字符串解析为可以操作的文档.
2. 配合aPath.快递的定位需要的网页元素
- 举一个例子:
```
from lxml import etree

html = """
<html>
    <body>
        <div class="movie">
            <h2>进击的巨人</h2>
            <p class="score">9.8</p>
        </div>
    </body>
</html>
"""

tree = etree.HTML(html)

name = tree.xpath('//h2/text()')
score = tree.xpath('//p/text()')

print(name) # ['进击的巨人']
print(score)  # ['9.8']
```
### 定位关键字:XPath
- 当有一个这样的html网页的时候:
 ```
<div class="container">
    <div class="item">
        <h2>进击的巨人</h2>
        <p>9.8</p>
    </div>

    <div class="item">
        <h2>咒术回战</h2>
        <p>8.9</p>
    </div>
</div>
```
>我们希望能够从中获取对应的元素,可以使用XPath.
- XPath常见的语法:
> <img width="771" height="298" alt="image" src="https://github.com/user-attachments/assets/f080fb93-f97c-4370-9435-e230482b296f" />
- /：从当前节点的直接子节点查找。
- //：从当前节点的后代节点中查找。
-  @：获取标签属性。
# 课程核心概念
- requests:获取网页
- lxml(etree): 解析网页
- XPath: 查找指定的元素.
``` python
import requests
from lxml import etree

# 1. 目标网址
url = "https://www.example.com"

# 2. 发送请求
response = requests.get(
    url,
    timeout=10
)

# 3. 检查请求是否成功
response.raise_for_status()

# 4. 获取 HTML
html = response.text

# 5. 解析 HTML
tree = etree.HTML(html)

# 6. 使用 XPath 提取标题
title = tree.xpath("//title/text()")

# 7. 输出结果
print(title)
```
