# Python 爬虫基础

## 一、网络机器人（爬虫）

- **爬虫（Web Crawler）**：简单来说，就是利用程序自动访问网页，获取网页中的信息，并将这些信息提取出来保存。
- **爬虫的主要作用**：自动获取网页数据，减少人工收集数据的工作量。

### 1. robots 协议

- robots 协议也称为爬虫协议、爬虫规则，是网站根目录下存放的一份文本文件，文件名为 `robots.txt`。
- 作用：告诉网络爬虫，网站中哪些页面允许抓取，哪些页面不希望被抓取。
- 通常被称为爬虫界的「君子协议」，它是一种网站与爬虫之间的访问约定，并不是技术上的访问权限控制，也不能代替法律法规或网站服务条款。

查看方式：

```text
https://网站域名/robots.txt
```

例如：

```text
https://www.example.com/robots.txt
```

常见规则：

| 规则 | 含义 |
|---|---|
| User-agent | 指定规则适用的爬虫 |
| Disallow | 不允许抓取的路径 |
| Allow | 允许抓取的路径 |
| Sitemap | 网站地图地址 |

## 二、爬虫的基本工作流程

爬虫的核心工作可以分为三个步骤：

**定义 URL → 发送请求 → 获取网页内容**

进一步结合网页解析，可以形成完整流程：

```text
定义目标 URL
     ↓
使用 requests 发送 HTTP 请求
     ↓
服务器返回 HTML
     ↓
使用 lxml 解析 HTML
     ↓
使用 XPath 定位目标元素
     ↓
提取所需数据
     ↓
保存数据
```

### 1. 第一个简单爬虫

```python
import requests

# 定义目标 URL
target_url = "https://hina-pc96.onrender.com/"

# 发送 GET 请求
response = requests.get(target_url)

# 输出网页内容
print(response.text)
```

代码说明：

- `target_url`：定义需要访问的网址。
- `requests.get()`：向目标网站发送 GET 请求。
- `response`：接收服务器返回的响应对象。
- `response.text`：获取服务器返回的网页文本。

## 三、网页的基本结构（前端）

网页前端主要由以下三种技术组成：

| 技术 | 主要作用 |
|---|---|
| HTML | 定义网页的结构与内容 |
| CSS | 控制网页的样式与布局 |
| JavaScript | 实现网页的交互与动态效果 |

爬虫主要需要关注 HTML，因为网页中的文字、图片地址、链接等信息，通常都可以从 HTML 结构中提取。

注意：

- 部分网页的数据是通过 JavaScript 动态加载的。
- 使用 requests 获取的 HTML 不一定包含浏览器最终显示的全部内容。
- 后续需要学习 Ajax、JSON 等动态数据获取方式。

## 四、网页解析

### 1. 什么是网页解析？

网页解析就是从原始的 HTML 代码中提取自己需要的信息。

例如：

原始 HTML：

```html
<div class="movie">
    <h2>进击的巨人</h2>
    <p class="score">9.8</p>
</div>
```

我们只需要提取：

```text
动漫名称：进击的巨人
动漫评分：9.8
```

### 2. 解析库：lxml

- lxml 是一个高性能的 HTML/XML 文档解析库。
- 主要作用：
  1. 将 HTML/XML 字符串解析为可以操作的文档树。
  2. 配合 XPath，快速定位需要的网页元素。

安装：

```bash
pip install lxml
```

导入：

```python
from lxml import etree
```

### 3. 使用 lxml 解析 HTML

例如，有以下 HTML：

```python
from lxml import etree

html = """
<html>
    <body>
        <div class="movie">
            <h2>进击的巨人</h2>
            <p class="score">9.8</p>
        </div>
    </body>
</html>
"""

# 将 HTML 字符串解析为 HTML 文档树
tree = etree.HTML(html)

# 提取动漫名称
name = tree.xpath('//h2/text()')

# 提取动漫评分
score = tree.xpath('//p/text()')

print(name)
print(score)
```

运行结果：

```python
['进击的巨人']
['9.8']
```

代码说明：

- `etree.HTML(html)`：将 HTML 字符串解析为 HTML 文档树。
- `tree`：保存解析后的文档树对象。
- `tree.xpath()`：使用 XPath 定位需要的网页元素。
- `text()`：提取标签内部的文本。

## 五、XPath：网页元素定位

### 1. 什么是 XPath？

XPath 是一种用于在 HTML/XML 文档树中定位元素的路径表达式语言。

简单来说：通过 XPath，可以快速找到 HTML 中指定的标签、文本和属性。

例如，存在以下 HTML：

```html
<div class="container">

    <div class="item">
        <h2>进击的巨人</h2>
        <p>9.8</p>
    </div>

    <div class="item">
        <h2>咒术回战</h2>
        <p>8.9</p>
    </div>

</div>
```

如果想提取动漫名称和评分，就可以使用 XPath。

### 2. XPath 常见语法

| XPath | 作用 |
|---|---|
| `//h2` | 查找所有 h2 标签 |
| `/html/body/div` | 从根节点按路径查找 |
| `//div[@class='item']` | 查找 class 为 item 的 div |
| `//h2/text()` | 提取 h2 标签内部的文本 |
| `//div/@class` | 获取 div 标签的 class 属性 |
| `//a/@href` | 获取 a 标签的 href 属性 |
| `//div[@class='item']//h2` | 查找指定 div 内部的 h2 |
| `(//h2)[1]` | 获取整个网页中第一个 h2 |

### 3. XPath 常见符号

- `/`：从当前节点的直接子节点查找。
- `//`：从当前节点的后代节点中查找。
- `@`：获取标签属性。
- `text()`：获取标签内部的文本。
- `[]`：添加筛选条件或位置条件。
- `()`：将 XPath 匹配结果作为一个整体进行分组。

### 4. XPath 两种位置定位方式的区别

```python
//div/p[1]
```

含义：找到每个 div 下面的第一个 p 标签。

```python
(//div/p)[1]
```

含义：先找到所有符合条件的 p 标签，再整体取第一个。

注意：

- XPath 的位置索引从 1 开始。
- Python 列表的索引从 0 开始。

## 六、requests + lxml：完整爬虫实例

前面分别学习了 requests 和 lxml，现在将两者结合起来，完成一个完整的网页爬取流程。

### 1. 爬取步骤

```text
1. 定义目标 URL
        ↓
2. requests 发送 GET 请求
        ↓
3. 检查 HTTP 响应状态
        ↓
4. 获取网页 HTML
        ↓
5. lxml 解析 HTML
        ↓
6. XPath 提取目标数据
        ↓
7. 输出提取结果
```

### 2. 完整代码

```python
import requests
from lxml import etree

# 1. 定义目标网址
url = "https://www.example.com"

# 2. 发送 GET 请求
response = requests.get(
    url,
    timeout=10
)

# 3. 检查请求是否成功
response.raise_for_status()

# 4. 获取 HTML 文本
html = response.text

# 5. 使用 lxml 解析 HTML
tree = etree.HTML(html)

# 6. 使用 XPath 提取网页标题
title = tree.xpath("//title/text()")

# 7. 输出结果
print(title)
```

### 3. 代码知识点

| 代码 | 作用 |
|---|---|
| `requests.get(url)` | 发送 GET 请求 |
| `timeout=10` | 设置请求超时时间为 10 秒 |
| `raise_for_status()` | 请求失败时抛出 HTTP 异常 |
| `response.text` | 获取网页 HTML 文本 |
| `etree.HTML(html)` | 解析 HTML |
| `tree.xpath()` | 使用 XPath 定位元素 |
| `//title/text()` | 提取网页标题文本 |

### 4. HTTP 常见状态码

HTTP 状态码用于表示服务器处理请求的结果。

| 状态码 | 含义 |
|---|---|
| 200 | 请求成功 |
| 301 | 永久重定向 |
| 302 | 临时重定向 |
| 403 | 服务器拒绝访问 |
| 404 | 请求的资源不存在 |
| 500 | 服务器内部错误 |

例如：

```python
print(response.status_code)
```

如果输出：

```text
200
```

说明服务器成功处理了本次请求。
