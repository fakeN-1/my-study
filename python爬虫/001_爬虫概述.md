# 网络机器人(爬虫)
- 按照指定的预设规则去自动抓取网络数据的程序或者脚本.
- robots协议也称为爬虫协议、爬虫规则，是指网站根目录下存放的一份文本文件robots.txt，用于告诉爬虫哪些页面可以抓取，哪些页面不能抓取。(君子协议)
